# Programador/a .NET para proyecto bancario (oferta inventada)

Vectora Consulting es una consultora ficticia que busca perfiles para un cliente del sector bancario.

**Qué harás**
- Desarrollo de servicios en .NET para el cliente final, dentro de su equipo.
- Seguir su metodología y sus herramientas internas.

**Qué pedimos**
- 3 años con C# y .NET.
- Disponibilidad inmediata.

**Qué ofrecemos**
- Salario a negociar según experiencia.
- Remoto, con posibilidad de ir a las oficinas del cliente cuando el proyecto lo pida.
